# 菲律賓厭氧沼氣場 3D 量體比較

互動式 3D 概念配置：100 m × 100 m、日處理 100 噸。

## 使用

以瀏覽器開啟 [index.html](./index.html)（建議透過 HTTP 伺服器，因為使用 ES Module 與 CDN）。例如：

```sh
python3 -m http.server 8000
```

開啟 http://localhost:8000/ 。也可在 GitHub Repository > Settings > Pages 啟用 `Deploy from a branch`，選擇 `main / (root)`。

**注意**：此儲存庫為 private，能否啟用 GitHub Pages，以及網站的存取限制，依 GitHub 帳號方案與 Pages 設定而定。目前程式碼已提交，但尚未確認 Pages 網址可用。

## 量體假設

- 基地：100 × 100 m (10,000 m²)
- 乾式方案：40 座 40 呎貨櫃，每座平面 12.192 × 2.438 m；高度以 High Cube 2.896 m 暫估；4 排 × 10 座
- 攪拌槽方案：3 座直徑 10 m、高 13.5 m 圓柱形槽體；總幾何容積 ≈ 3,181 m³
- 沼氣年產量：180 萬 m³，每小時平均約 205.5 m³
- 脫硫前與脫硫後各設 4 小時緩衝：每顆需約 822 m³ 有效容積，等效完整球體直徑約 11.62 m；不表示現場氣膜實際造型或設計使用率
- 發電機：以單座 40 呎貨櫃示意，550 kW（容納能力需廠商確認）
- 所有未提供長寬高的前處理、沼渣沼液處理、脫硫等附屬設施採概念量體；儲氣區與設備預留面積並非實際設備基礎面積。
- 未完成：地籍/法定退縮、防火間距、車道轉彎半徑、污水排水、物流量、地質與土建設計、物料與能量平衡、維修吊裝半徑。

## 360° 繞場動畫與影片錄製（2026-11-09）

側邊欄新增 **攝影機繞場動畫**：
- **開始繞場／暫停繞場**：攝影機沿以基地中心（50, 50 m）為軸的水平圓軌道旋轉，會自動停止在一圈結束時。
- **每圈秒數**：15／30／60 秒，預設 30 秒。
- **攝影機高度**：低空／中空／高空，預設中空。
- **重設**：停止動畫並恢復原本立體視角。
- **錄製影片**：重新從環繞起點開始，擷取目前 Three.js Canvas 影像；完成一圈後自動停止並下載，亦可提前停止。

影片格式依瀏覽器支援的 MediaRecorder MIME 類型決定，優先 MP4（H.264），否則 WebM（VP9／VP8）；部分瀏覽器或裝置不支援錄影。輸出為 Canvas 影像，不含側邊欄、HTML 標籤、音訊。影片長度／影格流暢度受瀏覽器、顯示卡與頁籤是否位於前景影響，正式對外簡報前應檢查成品。

保留透明背景 PNG 及包含場景的 PNG 功能。三種環境及乾濕兩種方案均可在繞場前切換；設備配置與尺寸不變。


## 多路徑攝影機動畫（2026-11-09）

「攝影機動畫路徑」可選擇：
1. **360° 全場環繞**：沿基地中心旋轉一圈。
2. **無人機低空巡場**：由入口側移動到主要設備區，再升高返回全場。
3. **俯視掃描全場**：從不同高空方位掃描配置。
4. **重點設備導覽**：依序聚焦前處理、厭氧反應器、儲氣、脫硫、發電及沼渣沼液處理。
5. **8 字型環繞**：以雙葉形航線呈現近距離與遠距離視角。

可設定 15／30／60 秒與低空／中空／高空；播放、暫停、重設及瀏覽器影片錄製沿用原有功能。錄製檔名會包含路徑識別字。攝影機路徑採概念性展示航線，**不是實際無人機飛行計畫**；部分路徑可能掠過虛擬設備或基地界線附近，後續可按展示需求微調關鍵影格。兩種厭氧處理方案均可使用，透明 PNG 截圖保留。

## 貨櫃模型效能升級：40 座乾式槽實例化及獨立發電機貨櫃（2026-11-09）

**本次已實作：**
- A 方案原有 **4 欄 × 10 列 = 40 座**乾式厭氧貨櫃，現在以 `THREE.InstancedMesh` 渲染，全部共用 **7 組材料／幾何繪製批次**（主殼體、波紋肋條、屋頂、門板、框架、門鎖、工藝管件）。同一批次的物件只儲存變換矩陣，不再為每條肋條、每座貨櫃建立獨立可繪製 Mesh。
- 貨櫃尺寸、基地座標、4 × 10 配置及 90° 水平轉向維持原設定。概念 ISO 40 呎 High Cube 外形為 **長 12.192 × 寬 2.438 × 高 2.896 m**。
- 將原本的發電機貨櫃替換成**單獨建立**的設備外觀，包含金屬側板、通風格柵、維修門、冷卻頂罩、排氣管與安全色標。這是一座 **550 kW 設計容量的外觀示意**，不是特定品牌發電機組的可驗證尺寸或通風配置。
- 以上均為**本專案直接建立的 Three.js 幾何與材質**，並非已下載的 NVIDIA SimReady 或其他第三方 GLB。原有 NVIDIA 素材仍用於前處理輸送與物流區。將來如取得合適且具授權的貨櫃 GLB，可把多個子網格依其相同 geometry/material 分批轉換為 InstancedMesh，以保留一份資產供 40 座重複使用。

**效能說明：** InstancedMesh 明顯降低大量重複物件的 CPU 場景管理及 GPU draw calls，但不代表只需 1 個 draw call（這版為 7 類批次），也不保證在所有 GPU 都有固定倍率的 FPS 提升。未啟用預先載入大體積貨櫃 GLB，不會因 40 座乾式槽而增加外部模型下載量。

**驗證範圍：** 已檢查 GitHub 原始碼與 JavaScript 語法，並核對 40 座配置、兩種厭氧方案、五種攝影機路徑、PNG 截圖與錄影邏輯仍存在；尚未完成真實瀏覽器 FPS／記憶體基準測試。
